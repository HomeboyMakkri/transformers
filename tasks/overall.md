НЕОБХОДИМО ДЛЯ НАЧАЛА РАБОТЫ:

Вам понадобится датасет для классификации тональности текстов (sentiment analysis).

Откуда взять данные:
1. IMDB Movie Reviews (двоичная классификация: positive/negative)
2. Twitter Sentiment Analysis ( positives/negative/neutral)
3. SST-2 (Stanford Sentiment Treebank)
4. Russian Sentiment Dataset (если хотите работать с русским языком)

Формат данных (CSV файл):
Минимум две колонки:
• text — текст отзыва/сообщения
• label — тональность (0/1 или 0/1/2)

Пример:
text,label
"This movie was absolutely amazing!",1
"Terrible experience, would not recommend.",0

---

СТРУКТУРА ПРОЕКТА:

Это один проект на 7 дней. Каждый день наслаивается на предыдущий:

День 1: Токенизация — учимся превращать текст в токены
День 2: Hidden states — получаем эмбеддинги из модели
День 3: Attention — визуализируем внимание модели
День 4: Baseline — классификация без дообучения
День 5: Fine-tuning — дообучаем модель
День 6: Сравнение — сравниваем baseline и fine-tuned
День 7: Анализ и приложение — разбираем ошибки и делаем демо

Совет: Создайте одну папку для проекта и работайте в ней всю неделю. Код из предыдущих дней будет использоваться в следующих.
